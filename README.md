# CraveYum 🍔🍕

A food-delivery themed webpage built as my Semester-1 capstone project using HTML and CSS.

This project focuses on layout design, visual structuring, and building a complete multi-section webpage from scratch. The main goal was to practice CSS Grid and understand how different sections of a real website come together.

---

## 🚀 Project Overview

**CraveYum** is a static front-end webpage that simulates a food discovery/delivery interface.
It includes:

* Landing section with search UI
* Navigation header
* Grid-based food gallery
* Multi-section page layout
* About & footer section

This project helped strengthen my fundamentals in webpage structuring and styling.

---

## 🛠️ Built With

* HTML
* CSS
* CSS Grid (Primary layout tool)
